Manga Kalbihan a Giyangka-iya Ummat

“Miya-aden kano a mapiya a pagetao, apiyakagemaw ko manga manosiya, a ipezogo íyo so okit a mapiya, go ipezapariyo so marata, go paparatiyaya-an niyo so Allah” (Sorah Ali ‘Imrán: 110)

Miyapanothol a so ‘Umar (Radhialláho ‘anho) na miyatharo iyan, “Saden sa tao a kabaya iyan a maped sangkanan a pagetao (ma-ana mapiya a pagetao), na tomanen niyan so manga sarat a tiyago-on o Allah (ma-ana izogo iyan so mapiya go izapar iyan so marata).” (Tafsir Ibni Kathir).
