Ta'lim

Antap o Ta’lim

  • Pakapheraraden ko poso so manga Katharo o Allah (Subhánaho wa Ta ’álá) ago so (Sogo lyan a) Rasülolläh (Sallalláho ‘Alaihi was Sallam)

  • Phamola-an ko manga poso so babaya ko kanggalebek sa mapiya ago so kapananggila-i ko marata.

  • So kapaka-khampeta a ko ‘Ilmo ago so ‘Amal (galebek)

  • So kapanagombalay o yaqeen (mabager a paratiyaya) ko (kanggalebek sa) A’mäl

Kalbihan

So Abu Hurairah (Radhialläho ‘Anho) ago so Abu Sa’id (Radhialláho ‘Anho) na palaya mizakesi sa miyatharo o Nabi (Sallalláho ‘Alaihi wa Sallam), “So kalilimod a mata laman ko taden-tadem ko Allah na lilibeten o manga Malá-ikat. So limo o Allah ago so Sakiina (kalilintad a mokama) na pethoron kiran ago so Allah na alowin Niyan siran ko lebi a mapiya ago maporo a kalilimod; (giyoto) so kalilimod o manga Malá-ikat. ’’(Muslim. Tirmidhi)

Pat (4) Timan a Ta ko Ta’lim

  • 1.    Ta'dhim - Phaki-ilay so pithamanan a pada-adat ko manga katharo o Alláh (Subhánaho wa Ta ’álá) ago so Hadith o Nabi (Sallalláho ‘A laihi wa Sallam)

  • 2.    Tasdiq - So katangkeda ago kasarig (Yaqin) ko Barakah o manga katharo o Nabi (Sallalláho ‘Alaihi wa Sallam) taros o kaparatiya-a ko kabebenar iran.

  • 3.    Ta’mil - So kinggolalanen ko manga Ayát sa Qur’an ago so manga Ahadith a miyabatiya sa Ta’lim

  • 4.    Tabligh - So kisampain non ko manga ped.

Telo a Pimba-adan o Ta’lim

Melagi-lagid so kalendo o oras a izenggay sangka-iya telo ba-ad (o Ta’lim):

  • 1.    Mbatiya-an so Fahdael Qur’an oriyan niyan na Modhákarah4 ko manga Surah (mbatiya-an so morí a sapolo a manga Surah).

    • 4Aya thanodan ko Antap o Surah Modhakarah na dowa a batang a “S” ago dowa a batang a “C”.

      S - Sunnah (so okit a kabatiya)

      S - Sawab (so balas o kabatiya)

      C - Correction (so kapaka-ontola ko pumbatiya)

      C - Concetration (so katekhesa ko pamikiran)

  • 2.    Mbatiya-an so Fahdael A’mal ago so Fahdael Sadaqat.

  • 3.    Modhákarah ko nem a sifat.

Okit okit o ka taalim

  • 1.    So kapamakot komabalaga ko (darepa a ron so) Ta’lim

  • 2.    So kaosar sa Miswak

  • 3.    So kadadalem ko abdas

  • 4.    So kakhakamotan

  • 5.    So kazambayang sa dowa ka rak’at a Sunnat5

    • 5Khapakay a mbida-bida so ni-at (sangkoto a dowa ka rakaat a Sunnat, lagid o Tahiyyatul Wudhu, Tahiyyatul Masjid, Salatol Hajat, Salatot Taubah, go so lagid iyan).

  • 6.    So kaontod sa lagid o kaontod sa tahayat igira gi-i ta sambayang

  • 7.    So kaontod rakhes o kapamamakineg phiya-piya

  • 8.    So karena ko babaya sa katharo, kainom sa ig, go so manga ped iyan a salakao san

  • 9.    So kazinganina ko Sorga igira miya-aloy so kapiya o Sorga

  • 10.    So kikaleken ko Naraka igira miya-aloy so pakaleklek ago so manga kasiksa-an non.

  • 11.    So kasalawat igira miya-aloy so ngaran o Nabí (Sallallaho‘ Alaihi wa Sallam)

  • 12.    So kaphed ko Ta’lim ipho-on sa poonan na taman sa kaposan

  • 13.    So kabatiya pho-on ko pimbarang a pinto ko kitab.
